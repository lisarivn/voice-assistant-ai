# Ukrainian TTS Model

This project uses the `uk_UA-ukrainian_tts-medium` voice model
from the Piper Voices collection.

## Model information

- Language: Ukrainian (`uk_UA`)
- Model: `ukrainian_tts`
- Quality: Medium
- Sample rate: 22050 Hz
- Speakers: lada, mykyta, tetiana
- Format: ONNX

## Source

The model is distributed as part of the Piper Voices collection:

https://huggingface.co/rhasspy/piper-voices/tree/main/uk/uk_UA/ukrainian_tts/medium
