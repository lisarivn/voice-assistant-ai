# 🎙️ AI Voice Assistant for Visually Impaired People

> Голосовий асистент для доступнішої взаємодії з цифровими технологіями для людей із порушеннями зору.

> 🚧 Проєкт перебуває в активній розробці.

## 💡 Про проєкт

AI Voice Assistant — проєкт голосового асистента, орієнтованого на доступність та голосову взаємодію з цифровими системами.

Основна мета — створити систему, у якій користувач може взаємодіяти з асистентом переважно за допомогою голосу: ставити запитання, отримувати голосові відповіді та використовувати допоміжні функції без необхідності постійної взаємодії з візуальним інтерфейсом.

На поточному етапі реалізовано базову голосову взаємодію за допомогою Speech-to-Text та Text-to-Speech.

---

## ✨ Реалізовано

- 🎤 розпізнавання мовлення (Speech-to-Text);
- 🔊 синтез мовлення (Text-to-Speech);
- 🇺🇦 підтримка українського мовлення;
- 🎙️ запис голосу безпосередньо у браузері;
- 🔄 передача аудіо між frontend та backend через HTTP API;
- ⚛️ вебінтерфейс на React;
- 📄 тестування API через Swagger UI.

## 🏗️ Архітектура

Проєкт складається з frontend та backend частин:

```text
Frontend
React + Vite
     │
     │ HTTP API
     ▼
Backend
FastAPI
   │
   ├── Whisper → Speech-to-Text
   │
   └── Piper   → Text-to-Speech
```

### Speech-to-Text

```text
Голос користувача
       ↓
MediaRecorder
       ↓
audio/webm
       ↓
POST /stt
       ↓
Whisper
       ↓
Розпізнаний текст
       ↓
React UI
```

### Text-to-Speech

```text
Введений текст
      ↓
POST /tts
      ↓
Piper
      ↓
WAV audio
      ↓
Відтворення у браузері
```

## 🎤 Speech-to-Text

Для розпізнавання мовлення використовується **OpenAI Whisper**.

Аудіо записується у браузері за допомогою `MediaRecorder` та передається на backend у форматі `audio/webm`.

FastAPI приймає файл через:

```text
POST /stt
```

Після обробки Whisper API повертає розпізнаний текст:

```json
{
  "text": "Привіт! Це тест розпізнавання мовлення."
}
```

Для поточної реалізації використовується модель Whisper `small`.

---

## 🔊 Text-to-Speech

Для синтезу мовлення використовується **Piper TTS**.

Початкова реалізація використовувала `pyttsx3`. Надалі її було замінено на Piper для покращення синтезу українського мовлення.

Поточна модель:

```text
uk_UA-ukrainian_tts-medium
```

Текст передається через:

```text
POST /tts
```

Backend генерує WAV-аудіо, яке повертається frontend та відтворюється у браузері.

Детальніша інформація про голосову модель:

[`backend/app/models/tts/MODEL_CARD.md`](backend/app/models/tts/MODEL_CARD.md)

## 🔌 API

Backend побудований на FastAPI.

| Method | Endpoint | Призначення |
|---|---|---|
| `POST` | `/stt` | Перетворення аудіо на текст |
| `POST` | `/tts` | Перетворення тексту на мовлення |
| `GET` | `/health` | Перевірка стану backend |

Під час локальної розробки інтерактивна документація API доступна через Swagger UI:

```text
http://127.0.0.1:8000/docs
```
